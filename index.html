02 // ARCHITECTURE

Homelab infrastructure

Hybrid self-hosted infrastructure spanning campus server nodes, home switch networks, and cloud egress. Interconnected via encrypted Tailscale mesh without requiring multiple internal cascading routers.

HYBRID TOPOLOGY · CAMPUS HOST + HOME SWITCH + MESH OVERLAY
COMPONENT 01

Campus server host (PNJ)

Primary server running on-campus behind the university network. Outbound Tailscale daemon circumvents strict inbound enterprise firewalls without exposing public open ports, hosting core containerized services and portfolio workloads.

Celery Node Docker Stacks Outbound Tunnel
COMPONENT 02

Home LAN switch distribution

Streamlined home topology: single ISP router feeding a gigabit unmanaged switch. Direct dedicated port to the local mini server; remaining ports distribute high-speed local connectivity across developer workstations, PC rig, and mobile devices.

ISP Gateway Gigabit Switch Mini Server
COMPONENT 03

Encrypted mesh & VPS egress

Encrypted Tailscale overlay establishes peer-to-peer WireGuard tunnels joining campus servers, home nodes, and client hardware into one flat private network. Cloud VPS acts as edge reverse proxy for public domain routing.

Tailscale Mesh WireGuard P2P VPS Egress
🔒

Internal homelab services (storage, media, cluster metrics, container dashboards) communicate strictly over the private WireGuard mesh. Only approved public portfolio routes transit through the VPS edge.
