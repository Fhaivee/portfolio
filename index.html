Infrastructure

My Homelab Environment

A production-grade self-hosted ecosystem — built from scratch, secured by design.

Layer 01

Physical Network
& Segmentation

Segmented dual-router architecture built entirely from budget and salvaged hardware. The primary router handles external traffic, while a dedicated secondary router routes directly to my lab environment — hardwiring the server, laptop, and experimental gear. Proof that great infrastructure doesn't need a big budget.

Dual-Router Hardwired Budget Builds
Layer 02

Ubuntu Server
& Containers

The core runs on Ubuntu Server for a stable, lightweight foundation. Applications are deployed using a heavily containerized Docker approach. Dockge provides an infrastructure-as-code interface to deploy, update, and monitor all container stacks.

Ubuntu Server Docker Dockge
Layer 03

Secure Access
& Tunneling

Dual-strategy security. Cloudflare Tunnels expose services externally — home IP fully hidden behind the edge network. Tailscale and ZeroTier provide encrypted mesh VPN overlays for private administrative access from anywhere in the world.

Cloudflare Tunnels Tailscale ZeroTier
